# Orbilap 1.0.0

Switch AI accounts in seconds and see usage at a glance.

- Switch saved Codex and Claude Code accounts from the macOS menu bar.
- Organize accounts into workspaces with independent sorting, switching, usage and menu-bar preferences.
- Track supported usage limits, reset times, subscription expiry and banked Codex resets.
- Check OpenCode connections and try experimental Antigravity support.
- Choose a light, dark or system theme and review updates before installing them.
- Light-theme buttons, fields and segmented tabs use distinct neutral fills for clearer control boundaries.
- Download smaller separate installers for Apple Silicon and Intel Macs, with an independently signed updater archive for each architecture.
- Project-owned styles and theme tokens consistently use the Orbilap name.
- The installer uses a white background with soft orbital accents so the app and Applications folder names remain readable in light and dark system appearances.
- Saved accounts and workspaces use Orbilap's own data folder, separate from development builds and OpenCode.
- Removing Orbilap's app data keeps reinstallations empty; accounts are not restored automatically from legacy stores.

Choose the [Apple Silicon installer](https://github.com/amirmahdinezhad/orbilap/releases/download/v1.0.0/Orbilap_1.0.0_aarch64.dmg) for M-series Macs or the [Intel installer](https://github.com/amirmahdinezhad/orbilap/releases/download/v1.0.0/Orbilap_1.0.0_x64.dmg).

See the [macOS installation guide](https://github.com/amirmahdinezhad/orbilap#install-on-macos) for the first launch of the ad-hoc signed app. Earlier development installations require a manual install. Existing provider sign-ins can be discovered again during setup.

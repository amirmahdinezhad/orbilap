# Security review for Orbilap 1.0.4

## Results

- Reviewed the pending changes against v1.0.3. The native change uses bar-local coordinates in the menu-bar renderer. The development supervisor registers a per-user launchd job with KeepAlive disabled and passes a fixed allowlist of environment variable names. Account storage, network requests, production IPC and updater trust configuration have no changes.
- TypeScript, 494 Vitest tests, 8 release tests, locked offline Cargo check and 299 locked offline Rust tests passed. Ten opt-in Rust tests were skipped. Native test coverage includes fractional progress markers and narrow reset timeline fills. The dev panel opened with WebKit connected to Vite. The dev supervisor's Quit behavior was previously verified with both supported launch commands.
- The 2026-11-21 security gate passed against the versioned 1.0.4 source and lockfiles. pnpm 10.24.0 reported no known vulnerabilities. Gitleaks 8.30.1 found no leaks in files or history. cargo-audit 0.22.2 checked the macOS dependency union against 1,555 RustSec advisories. Full-lockfile findings in ZIP, Chrono, GTK and Linux IPC dependencies were outside the macOS build trees.
- GitHub withdrew [GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf). The lockfile resolves picomatch 4.0.7, the latest npm release at review time.

## Remaining verification

- Verify both architecture-specific DMGs, code signatures, updater archives and signatures, tamper rejection, checksums and public feed. Verify the update flow using a disposable installed copy. The publication command reruns the security gate at the tagged commit.
- Live provider sign-in, account import and installation on physical Intel hardware were outside this pre-release check.

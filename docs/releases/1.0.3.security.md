# Security review for Orbilap 1.0.3

## Results

- Reviewed the reconnect IPC and local profile cleanup. A native setup draft binds the target profile. Deletion requires a provider-confirmed Free plan and a matching ChatGPT subject and workspace. Unknown plans, failed verification and mismatched identities leave the profile available for retry.
- The reconnect flow uses private staging storage and the existing scoped provider requests. The panel receives account metadata and the removal result. No credential values are returned to the webview or recorded in test logs.
- TypeScript and all 494 frontend tests passed. The locked offline Rust suite passed 298 tests and skipped 10 opt-in tests. Synthetic native IPC testing of the same reconnect implementation verified identity mismatch rejection and removal from two workspaces.
- GitHub withdrew the [picomatch advisory](https://github.com/advisories/GHSA-fc5q-39xc-vjpf). The lockfile resolves 4.0.7, the latest version reported by npm during this review.
- The security gate passed for both macOS targets. npm audit reported no known vulnerabilities, Gitleaks found no leaks and Cargo Audit checked the resolved macOS dependency union against 1,550 RustSec advisories. The full lockfile reported ZIP, Chrono, GTK and Linux IPC findings outside the macOS build trees.

## Remaining verification

- The public release requires fresh verification of both updater signatures, both DMGs and the public feed. Live provider sign-in and physical Intel execution were outside the synthetic test scope.

# Orbilap 1.0.3

- Reconnecting a saved Codex account now removes its local profile from Orbilap and all its workspaces when ChatGPT confirms the same account is on the Free plan.
- Workspace refresh uses the current plan reported by ChatGPT, so an outdated Plus label no longer keeps a confirmed Free account visible.
- Accounts that still need you to sign in show a compact recovery message and Reconnect button on the standard home card.

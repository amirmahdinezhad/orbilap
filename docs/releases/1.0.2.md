# Orbilap 1.0.2

- Settings → Updates stays steady while checking for a release and smoothly resizes when a release appears or you skip it.
- What's new opens a separate dialog so you can read the release notes without expanding the update card.
- The download progress bar fills smoothly. When the download finishes, choose Install & relaunch when you're ready.
- Check updates keeps its button background while checking and shows a focus ring during keyboard navigation.

# Orbilap 1.1.0

- Added an optional floating usage orb with a separate quota selection for each service, saved position, and one segmented progress ring.
- Added a configurable global keyboard shortcut to open and dismiss the panel.
- Added unread update indicators while keeping download and installation as separate choices.
- Refined Display settings, provider limit controls, radio buttons, and disclosure animations.
- Improved Antigravity shared quota groups and reconciliation of expired paid plans.
- Improved Codex plan-aware menu bar defaults, small remaining percentages, banked reset balances, and expired reset notices.
- Duplicate account imports now explain that the account already exists without showing an error.
